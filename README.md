# Smartronics

Smartronics is a full-stack MERN (MongoDB, Express, React, Node.js) web application for selling electronic devices online.

## Features

- User authentication and authorization
- Browse and search products
- Shopping cart and checkout functionality
- Order management system
- Responsive design for all devices

## Technology Stack

- Frontend: React.js
- Backend: Node.js, Express.js
- Database: MongoDB
- Authentication: JWT
